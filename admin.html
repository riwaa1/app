المؤذنون

أضف مؤذناً، ثم ارفع ملف صوته (mp3) أو ضع رابطاً، واستمع إليه هنا قبل الحفظ. يظهر للمستخدمين في الإعدادات مع زر استماع.

المساعد الذكي

اكتب ما تريد بالعربية وسيجهّزه لك داخل اللوحة. لا يُنفَّذ أي تعديل قبل موافقتك (الحذف يسأل دائماً). يعمل بمفتاح API من المزوّد الذي تختاره، وفيه خيارات مجانية بحدود استخدام.

Ctrl+Enter للإرسال. راجع كل تعديل قبل الموافقة، وخصوصاً النصوص الدينية.
